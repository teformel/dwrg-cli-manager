# 常见问题排查

以下错误信息均取自源码中的真实文本。表格按「错误信息 → 原因 → 解决」组织。

## 一、安装与运行

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `dwrg: command not found` | 未安装，或脚本目录不在 `PATH` | 参照 [开始使用](getting-started.md) 安装；pipx 用户执行 `pipx ensurepath` 后重开终端；venv 用户先激活环境 |
| `Error: No such command 'xx'`（退出码 2） | 命令名拼写错误或该子命令不存在 | 运行 `dwrg help` 查看真实命令树 |
| `Error: Missing option '--username'`（退出码 2） | 缺少必填选项 | 补全选项；`account add` 的 `--username` / `--password` 为必填 |
| `已取消`（退出码 130） | 用户按下了 `Ctrl+C` | 预期行为，重新执行命令 |

## 二、配置相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `配置错误: 配置文件解析失败` | YAML / JSON 语法错误 | 按文件扩展名确认格式，修复语法；或删除 `~/.config/dwrg/config.yaml` 让其重建 |
| `配置错误: 配置文件根节点必须是映射` | 文件顶层不是对象（如写成了列表或标量） | 改为 `app` / `servers` / `accounts` 三键的对象结构 |
| `配置错误: 配置文件内容不合法` | 字段类型 / 取值不符合模型 | 对照 [配置](configuration.md) 的字段表修正；注意 `log_level` 取值与 `max_concurrent_downloads` 的 1–10 范围 |
| `配置错误: 配置文件读取失败` | 文件存在但无读权限 | 检查文件权限（应可读） |
| `配置错误: 配置文件写入失败` | 目录不存在或不可写 | 确认 `~/.config/dwrg/` 可写 |
| `配置错误: 不支持的配置项: <key>，可用: ...` | `config set/unset` 使用了非 `AppConfig` 字段 | 从错误信息列出的可用键中选择 |
| `配置错误: 配置项 <key> 取值不合法` | 值不满足约束（如 `language` 不受支持、并发数为 0） | 按约束范围重新取值 |
| `✗ 配置项不存在: <key>`（`config show --key`） | 键不存在，或误写成 `app.log_level` 被拼成 `app.app.log_level` | 子键直接写 `log_level`；顶层键写 `app` / `servers` / `accounts` |
| `配置错误: 待导入的配置文件不存在: <path>` | `config import` 路径错误 | 检查路径；支持 `~` 展开 |
| `配置错误: 不支持的导出格式: <fmt>` | `config export --format` 取值非 `yaml` / `json` | 使用 `yaml` 或 `json` |

## 三、账号相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `参数错误: username: 长度必须在 3-20 个字符之间` | 用户名长度越界 | 调整到 3–20 个字符 |
| `参数错误: username: 只能包含字母、数字和下划线` | 用户名含非法字符 | 仅使用 `[A-Za-z0-9_]` |
| `参数错误: password: 长度必须在 6-128 个字符之间` | 密码长度越界 | 调整到 6–128 个字符 |
| `参数错误: password: 不能全部为空白字符` | 密码全为空白 | 提供有效密码 |
| `账号ID长度不能少于8个字符`（模型层校验信息） | 账号 ID 过短 | 使用命令生成的完整 UUID；如需自定义 ID，长度 ≥ 8 |
| `账号错误: 用户名已存在: <name>` | 用户名重复 | 更换用户名，或先删除旧账号 |
| `账号错误: 渠道服不存在: <server>，可用: ...` | `--server` 指向了不存在的渠道服 | 先 `dwrg server list`，或 `dwrg server add` 新增 |
| `账号错误: 账号不存在: <id>` | 账号 ID 错误，或账号已删除 | `dwrg account list` 核对 ID |
| `账号错误: 该账号未保存密码密文` | 账号没有 `encrypted_password` | 用 `AccountManager.set_password` / 重新添加账号 |
| `账号错误: 密码解密失败（可能由旧版本密钥加密）` | 密文由旧密钥加密，当前密钥文件不匹配 | 恢复原 `~/.dwrg/keyfile`，或通过 `DWRG_ENCRYPTION_KEY` 提供原密钥 |
| `✗ 账号不存在: <id>`（switch / remove） | 切换 / 删除不存在的账号 | 先用 `account list` 确认 ID |

## 四、渠道服相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `✗ 渠道服不存在: <name>` | `switch` / `remove` / `set-default` 指向不存在的渠道服 | `dwrg server list` 查看可用名称 |
| `✗ 未找到渠道服: <name>` | `server show` / `info` 名称错误 | 同上 |
| `! 暂无渠道服` | 配置中没有任何渠道服 | `dwrg server add` 新增，或删除配置文件让其重建内置三项 |
| `! 未设置当前渠道服` | `app.server` 为空或指向不存在的渠道服 | `dwrg server set-default <name>` |
| `! 未能探测到可用渠道服（离线环境下属正常）` | 所有渠道服探测失败 | 检查网络；离线环境属预期 |
| 探测结果 `offline` / 延迟显示 `超时` | 该渠道服不可达 | 该渠道服被标记为 `inactive`，选择其它渠道服 |
| `渠道服错误: 服务器连接失败` / `网络请求失败` | 渠道服探测网络异常（记入日志） | 检查网络或代理 |

## 五、资源相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `✗ 资源更新失败`（`error=无法获取资源清单`） | 资源服务器不可达或返回非 200 | 检查网络；离线环境无法更新 |
| `无法获取资源清单（服务器: <name>）` | 指定了不存在的资源服务器 | `--server` 仅支持内置的 `official` / `backup` |
| `资源检查结果：文件总数 0` | 清单拉取失败（降级为全 0） | 属离线预期；恢复网络后重试 |
| `大小校验失败: <total> != <expected>` | 下载不完整 | 下载器会保留 `.part` 并重试；可 `dwrg resource clean` 后重试 |
| `MD5 校验失败` | 文件内容与清单不符 | 下载器删除 `.part` 并重试；持续失败时检查网络中间层 |
| `HTTP 状态码 <code>` | 服务器返回非 200/206 | 重试；确认资源服务器可用 |
| `服务器拒绝 Range 请求(416)` | `.part` 与远端不匹配 | 下载器会删除 `.part` 并重下；必要时 `dwrg resource clean` |
| `创建目录失败: <err>` | 目标目录不可写 | 检查 `data_dir` / `cache_dir` 权限 |
| `✗ 缓存清理失败` | 目录删除时权限不足或被占用 | 关闭占用进程后重试 |

## 六、启动相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `✗ 未找到游戏可执行文件（已尝试 DWRG_GAME_PATH 与默认安装路径）` | 未探测到客户端 | 设置 `DWRG_GAME_PATH` 指向可执行文件；`dwrg diagnose` 可查看探测结果 |
| `启动错误: 账号不存在: <id>` | 指定的 `--account` 不存在 | `dwrg account list` 核对 |
| `启动错误: 渠道服不存在: <name>` | 指定的 `--server` 不存在 | `dwrg server list` 核对 |
| `✗ 停止游戏失败` | 进程已退出或权限不足 | 通常可忽略；确认进程归属 |
| `! 游戏未在本会话中运行` | 游戏进程由其它会话启动，或已退出 | 预期行为；状态仅在启动它的进程内可见 |
| 启动诊断建议 `可用磁盘空间不足 10 GiB，建议清理磁盘` | 磁盘剩余低于 10 GiB | 清理磁盘 |
| 启动诊断建议 `账号配置无效: <id>` / `渠道服配置无效: <name>` | 当前账号 / 渠道服已被删除 | 重新设置当前账号 / 渠道服 |

## 七、插件相关

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `插件错误: 插件未发现: <name>` | 插件不在插件目录，或入口文件缺失 | 确认 `~/.dwrg/plugins/` 下的目录 / 文件命名 |
| `插件错误: 插件入口文件不存在: <path>` | 元数据记录路径与磁盘不符 | 重新放置插件文件 |
| `插件错误: 加载插件 <name> 失败: <err>` | 插件代码导入时抛异常 | 查看插件代码与日志中的完整堆栈 |
| `插件错误: 插件 <path> 中未找到 Plugin 子类` | 入口文件未定义 `Plugin` 子类 | 确保类继承 `from dwrg_manager.plugins import Plugin` |
| `非法插件名: '...'，仅允许字母、数字、下划线与连字符`（校验层信息） | 文件名 / 目录名含非法字符，或显式加载时名称非法 | 重命名为 `[A-Za-z0-9_-]+` |
| `非法版本号: '...'，需符合 x.y.z`（校验层信息） | `version` 类属性格式错误 | 使用 `x.y.z` 形式 |
| `✗ 启用失败: <name>` / `✗ 禁用失败: <name>` | 名未知或 `on_enable` 抛异常 | `dwrg plugin list` 确认名称；检查插件回调 |
| `插件错误: 写入插件状态文件失败: <err>` | `plugins.json` 不可写 | 检查插件目录权限 |
| `! 未发现插件` | 插件目录为空或不存在 | 放入插件文件后重试 |

## 八、安全与密钥

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `安全错误: 密钥文件内容非法，请检查或删除后重建` | `~/.dwrg/keyfile` 内容不是合法 Fernet 密钥 | 删除该文件使其重建；若已有密文将无法解密，请先备份 |
| `安全错误: 无法从给定输入派生出可用密钥` | `DWRG_ENCRYPTION_KEY` 既非法又无法作为口令派生 | 提供合法 Fernet 密钥或普通口令 |
| `安全错误: 解密失败：数据无效或密钥不匹配` | 密文损坏或密钥不一致 | 恢复原密钥文件 / 环境变量 |
| 日志警告 `无法写入密钥文件 <path>（将仅在本次进程内有效）` | 密钥文件不可写 | 修复权限；否则重启后旧密文无法解密 |
| `安全错误: 写入新密钥失败` | 轮换密钥时目标不可写 | 检查目标目录权限 |

## 九、国际化

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `不支持的语言: <lang>`（`ValidationError` 的 `user_message`，即校验 / API 层信息） | 语言代码不在 9 种受支持语言内 | 使用 `zh-CN` / `zh-TW` / `en-US` / `ja-JP` / `ko-KR` / `fr-FR` / `de-DE` / `es-ES` / `ru-RU`；`config set language` 传入非法值时另见 `配置项 language 取值不合法` |
| 文案仍为中文（`--lang en-US` 无效） | 该语言的目录文件不存在，回退到 `zh-CN` | 预期行为；补充对应 `locales/<lang>.json` 后生效 |
| 日志警告 `语言初始化失败，回退默认` | 配置文件损坏，无法读取语言 | 修复配置；命令仍可继续执行 |

## 十、诊断与日志

| 目的 | 操作 |
|------|------|
| 获取完整环境报告 | `dwrg diagnose --output report.json` |
| 打开终端日志 | 全局追加 `--verbose` / `-v`（日志级别切到 `DEBUG` 并输出到终端） |
| 查看文件日志 | `~/.dwrg/logs/dwrg.log`（单文件 5 MiB 滚动，保留 5 份） |
| 机器可读输出 | `dwrg server list --format json` / `dwrg account list --format json` / `dwrg plugin list --format json` |
| 自定义配置排查 | 为支持的命令追加 `--config /tmp/test.yaml`，避免污染主配置 |
